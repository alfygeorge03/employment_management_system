# Employment Management System

The application is built using PHP and CodeIgniter framework with MySQL database integration. It includes secure login authentication using sessions, responsive user interface, employee CRUD operations, dashboard analytics, and export features for PDF and Excel reports.

## Key Features

* Secure Login & Session Authentication
* Employee Management (Add, Edit, Delete, View)
* Responsive Admin Dashboard
* Search Employees
* Export Employee Data to Excel and PDF
* DataTables Integration
* Bootstrap Responsive UI
* MySQL Database Integration

## Technologies Used

* PHP
* CodeIgniter 4
* MySQL
* Bootstrap 5
* JavaScript
* jQuery
* DomPDF
* PhpSpreadsheet

## Purpose of the Project

The main objective of the Employment Management System is to simplify employee data management and improve administrative efficiency within an organization. The system reduces manual work, ensures secure data handling, and provides organized access to employee information.
